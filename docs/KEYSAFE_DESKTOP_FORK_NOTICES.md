# NetAigis KeySafe (Desktop) — attribution

NetAigis KeySafe on the desktop is a modified fork of KeePassXC by the KeePassXC
Team and other contributors. Original source-level copyright and license headers
are preserved. Upstream: https://github.com/keepassxreboot/keepassxc

NetAigis modifications include HTTPS-coordinated KDBX access, related security
limits, and independent application identifiers/branding
(`de.netaigis.keysafe.desktop`, display name **NetAigis KeySafe**).

This is **not an official KeePassXC application** and is not endorsed by the
upstream maintainers. Internal CMake project/library names may still say
KeePassXC for upstream mergeability; they are not the installed product brand.

Corresponding Source under GPL must continue to be provided when binaries are
conveyed.
